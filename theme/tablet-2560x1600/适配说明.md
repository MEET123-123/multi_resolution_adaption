# HarmonyOS 4.x 平板主题适配

交付日期：2026-10-15。目标横屏 2560×1600，同时提供竖屏 1600×2560。

可安装文件：

- `比邻熊 新拟态 平板2560x1600.hwt`，约 19.7 MiB。
- `线条小狗 夏日出逃 平板2560x1600.hwt`，约 16.2 MiB。

这次制作的是重新排版的平板动态小主题，包含动态锁屏、壁纸、图标、平板桌面模块、描述文件和主题预览图。原始两个 HWT 未改动，SHA256 已写入各自的 `validation.json`。

## 适配内容

比邻熊：保留原包五套熊角色帧素材；重新制作平板拟态卡片，横屏采用左侧时间与角色、右侧 2×2 卡片的排版，竖屏采用上下排版。提供实时时钟、指针时钟、日期、电量和充电状态，支持深浅色切换、五种角色换装、角色动画开关。

线条小狗：保留原包小狗与漂浮物透明帧素材；水面背景经过 imagegen 扩展，再按规范尺寸导出。横竖屏分别编排时间、两只小狗和漂浮装饰，支持四组造型切换与角色动画开关。背景是静态水面，角色使用原始帧动画并增加轻微漂浮；没有保留原包 WaterWallpaper 触摸水波和重力感应。

两个包均保留原作者/设计师署名和原图标资源。为减少手机专用配置在平板上的冲突，未移植原包拨号、短信、控制中心等大主题换肤、AOD、桌面万象小组件，以及复杂的手机设置菜单、倒计时、天气、计步和应用快捷入口。主题锁屏不会新增应用启动权限。

## 官方规范依据

已通过浏览器读取[华为《平板主题设计指导及规范》](https://developer.huawei.com/consumer/cn/doc/content/tablet-themes-specification-0000001078779076)，位于“手机/折叠屏/平板主题规范区别（HarmonyOS 4.x及以下版本）”，页面标注更新时间 2025-12-18。

| 项目 | 本次输出 |
|---|---|
| `description.xml` | `screen=WUXGA`，平板版本号 `11.1.0`，默认字体 |
| 默认锁屏 | `unlock/lockscreen/manifest.xml`，`screenWidth=1080` |
| 横屏锁屏 | `unlock/lockscreen/1600_2560_manifest.xml`，`screenWidth=2560` |
| 竖屏锁屏 | `unlock/lockscreen/2560_1600_manifest.xml`，`screenWidth=1600` |
| 壁纸 | `home_wallpaper_0.jpg`、`unlock_wallpaper_0.jpg`，均为 3200×2560 JPG |
| 主题引擎 | `HWThemeEngine`，`unlock/theme.xml` 指向 `lockscreen` |
| 桌面模块 | 保留原资源，删除其中手机专用 `framework-res-hwext` |
| 横屏预览 | `cover_land.jpg` 为 1920×1080，其他横屏预览为 2160×1080 |
| 预览数量 | 不超过 20 张 |

注意官方脚本文件名顺序是 **高_宽**。3200×2560 是平板静态壁纸规范尺寸；2560×1600 是本次横屏锁屏画布尺寸，二者用途不同。

另参考[HarmonyOS 4.x 引擎更新指导](https://developer.huawei.com/consumer/cn/doc/distribution/content/themes-engine-update-0000001055348462)和[引擎注意事项](https://developer.huawei.com/consumer/cn/doc/content/themes-engine-notes-0000001055508442)。没有把 HarmonyOS 5+ 的脚本要求混用进来。

## 检查结果与限制

生成器检查了 ZIP 完整性、XML 语法、三个脚本的方向与 screenWidth、壁纸尺寸、桌面模块、预览数量、主要控件边界、造型/深浅色/动画开关组合下的资源引用，以及点击与上滑解锁命令条件。两个包都通过，报告见主题子目录的 `validation.json` 和总 `validation-summary.json`。

横竖屏及深色、造型预览已经离线渲染并人工检查。图片来自同一份输出 XML 的离线绘制，显示时间与电量是预览样本；真实包中使用系统实时时间和电量。预览字体与鸿蒙设备的系统字体可能不同。

当前环境没有可用的已连接华为平板或官方 Theme Studio 引擎校验环境，**未进行 HarmonyOS 真机安装、原生动画、系统通知、安全认证界面及横竖屏切换测试**。这些是设备验收项，不能由 ZIP/XML 检查代替。此交付是本地试装版本，未作主题商店上传或审核。

## 导入

将 `.hwt` 文件复制到平板内部存储的 `Huawei/Themes/`，重新打开“主题 → 我的 → 我的主题”，选择对应“平板版”主题应用。文件保持 `.hwt` 后缀，不需要解压。不同系统和主题 App 版本的本地导入入口可能不同。

试装时检查：横竖屏切换；亮灭屏后造型与颜色；三个或两个按钮的点击；从空白区域及按钮区域向上滑动；充电、通知、密码/指纹界面。原系统的安全认证流程由系统处理。

## 工程文件

`build_tablet_themes.py` 为可重复构建脚本；需要 Pillow，运行目录不限。主题子目录包含三个输出脚本、布局记录、原脚本备份、横竖屏及造型预览和校验报告。`index.html` 是本地预览画廊，可直接用浏览器打开。

`sea-master.png` 是新增水面底图；生成来源与完整提示词见 `image-generation.md`。
