## 2. 样本与筛选

每条包括源图、源组件角色/源框/锚点、目标逻辑画布、安全区和目标根组框。目标渲染供核验；训练用户消息只读取源图。源分组中未知角色明确保留 `unknown`。

构建中校对原包与缓存脚本、抽样状态使用的缓存位图字节、原包及缓存 SHA；按状态覆盖选择代表帧，不把所有相邻动画帧重复扩样。同源包、相同脚本和高度相近模板归入同一家族，再按家族拆分。

家族相似度采用脚本四节点片段的 Jaccard 阈值 0.88，是保守的自动规则，不是人工家族认证。家族拆分约束通过；语义近似模板仍存在自动识别边界。

排除 205 对：

- 170 对源/目标离线渲染不完整，包括外部照片、天气素材或不支持的原生效果。
- 26 对存在几何/布局契约问题或检查结果不确定。
- 9 对超过 16 个根组，保留在复杂场景队列，不截断节点来凑训练样本。

此外保留求解失败/缓存入口问题。`excluded.jsonl`、`source-provenance.json`、`statistics.json` 和各 worker 日志记录具体原因。被排除的来源没有被伪装成成功样本。

219 对的源归一化框与目标框均有非平凡变化；平均坐标变化约 102.08/1000。这是变化量，不是质量得分。自动检查不替代审美评审、交互回放或真机验收。

## 3. 包里包含什么

- `train.jsonl / validation.jsonl / test.jsonl`：图文 SFT，图片路径相对包根目录。
- `pairs.jsonl / samples.jsonl`：完整布局对和推理索引；标签不会作为推理用户输入。
- `images/`：源图及适配目标图。
- `evidence/`：元素/组件/布局证据、原始关系、状态、组件映射、目标变换和检查记录。
- `manifest.json / sample-index.jsonl`：数量、来源性质、家族拆分及输入策略。
- `verification.json / token-preflight.json / file-sha256.json`：数据、处理器、文件完整性检查。
- `gallery.html / contact-sheet.jpg`：所有通过样本的对照页及抽样总览。
- `code/`：本次训练/推理运行所需源码、配置与依赖清单。
- `train_server.sh / build_training_pairs.py / preflight_tokens.py`：服务器启动、数据验证、评分与图文预检。

服务器只需此包与模型、运行依赖，无需复制本机 HWT 或解析缓存。

## 4. 上传服务器后执行

解压进入包根目录。在服务器准备兼容 GPU 的 CUDA PyTorch 环境，安装 `code/requirements-ml.txt`；它已列出核心图像与求解依赖。GPU 的 PyTorch 版本需按服务器 CUDA 环境选择，本包不包含模型权重或 CUDA 运行环境。

```bash
python build_training_pairs.py verify --run .

# 必须指向本地已有模型目录。当前 CPU 预检使用 Qwen3-VL-2B-Instruct。
# 换模型/处理器时先重新执行预检；这一步不加载模型权重。
python preflight_tokens.py --bundle . --processor-model /path/to/Qwen3-VL-model --out token-preflight-server.json

MODEL_PATH=/path/to/Qwen3-VL-model GPU_COUNT=2 bash train_server.sh
```

训练脚本会切换到包根目录，修复 Windows 到 Linux 的绝对路径问题；显式传入 `--allow-weak`，说明这是算法监督。默认 100 个优化步是工程起点，不代表已收敛，可通过 `MAX_STEPS` 修改。没有 BF16 的显卡可以在命令末尾追加 `--precision fp16`。

当前训练入口读取 train，不会自动使用验证集进行早停或选模型。完成后分别跑底座和微调模型的测试集推理：

```bash
export PYTHONPATH="$PWD/code/src${PYTHONPATH:+:$PYTHONPATH}"
MODEL_PATH=/path/to/Qwen3-VL-model
python -m multires_app.learning.qwen_runner infer \
  --model "$MODEL_PATH" --adapter "$PWD/adapter-run-1" \
  --dataset "$PWD" --split test --limit 1000 \
  --max-pixels 200704 --max-length 8192 --max-new-tokens 2048 \
  --out lora-predictions.json
python build_training_pairs.py score --run . --predictions lora-predictions.json
```

去掉 `--adapter` 并使用不同输出文件名，得到底座对照。评分报告包括 JSON 合法率和相对自动教师的 MAE，不冒称人工评价。最终约束后布局、XML/热区和真机检查仍在原业务项目中执行。

## 5. 重建与复现

在本项目根目录运行。新运行应使用新的 `--run`；旧数据不覆盖。构建按单主题进程隔离，可恢复已完成 worker。

```powershell
.\.venv\Scripts\python.exe theme-layout-dataset/build_training_pairs.py build --run theme-layout-dataset/runs/auto-pairs-v2 --jobs 2
.\.venv\Scripts\python.exe theme-layout-dataset/build_training_pairs.py finalize --run theme-layout-dataset/runs/auto-pairs-v2
.\.venv\Scripts\python.exe theme-layout-dataset/build_training_pairs.py verify --run theme-layout-dataset/runs/auto-pairs-v2/server-bundle
.\.venv-ml\Scripts\python.exe theme-layout-dataset/preflight_tokens.py --bundle theme-layout-dataset/runs/auto-pairs-v2/server-bundle --processor-model artifacts/models/Qwen3-VL-2B-Instruct-sharded
.\.venv\Scripts\python.exe theme-layout-dataset/build_training_pairs.py bundle --run theme-layout-dataset/runs/auto-pairs-v2
```

原始包和缓存保持原样。此次新增的构建/隔离/泄漏检查测试与既有标注检查共 9 项通过；实际数据又经过 219 条逐条验证及真实图文处理器预检。
