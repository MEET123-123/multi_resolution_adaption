# 本地微调结果

已使用本机 RTX 4060 8GB，基于本地 Qwen3-VL-2B-Instruct 分片模型完成一次真实 QLoRA 微调。起点为未微调底座，没有沿用此前 mock 适配器。

**本轮验证损失下降，但测试子集坐标误差变差，不能认定模型布局能力已提升。** 保留该轮作为可复现的基线实验，不把它标记成质量优于底座的版本。

## 训练配置与完成证据

| 项目 | 实际值 |
|---|---|
| 训练数据 | 140 条，随机打乱后完整训练一轮，每条恰好一次 |
| 验证数据 | 全部 24 条，不参与参数更新 |
| 量化 / LoRA | NF4 4 位、双重量化；rank 8；仅语言模型 q/k/v/o 投影 |
| 学习率 | 峰值 1e-4；预热后余弦衰减 |
| 批量 | 微批次 1，梯度累积 4；共 35 次优化更新 |
| 图像 / token 预算 | max_pixels=100352；max_length=4096 |
| 随机种子 | 23 |
| 可训练参数 | 3,211,264 |
| 已改变的适配器张量 | 224 |
| 视觉编码器 | 冻结 |
| PyTorch 峰值已分配显存 | 3.884 GiB（不等于驱动显示的全部占用） |
| 训练及验证用时 | 252.4 秒，不含模型加载与后续生成 |

原训练文件哈希、运行配置、每条样本的访问顺序、逐步损失、检查点和适配器哈希均保存于运行目录。

## 验证与生成结果

| 指标 | 底座 | 本轮微调后 |
|---|---:|---:|
| 24 条验证集的助手 token 加权损失 | 1.408504 | 1.304877 |
| 固定测试子集 JSON/组 ID 合规 | 6/6 | 6/6 |
| 相对自动教师的坐标 MAE / 1000 | 97.25894 | 119.32458 |

验证损失相对下降约 7.36%。测试子集为训练前固定的 6 条：每个测试家族、每种目标设备一条，按源任务复杂度选取，不依据目标坐标或模型预测挑样。它只覆盖完整 55 条测试集中的一部分，不能作为充分的泛化评估。

坐标误差对同样 6 条、同样合法组集合计算，直接评价原始模型输出，未经过约束求解器投影。目标来自算法教师，不是设计师金标，也未进行真机验收。

损失和实际坐标指标方向不一致，说明不能仅依赖语言模型损失判断布局训练是否有效。当前证据不能确定退化的单一原因；后续应先在验证集增加实际生成几何指标，用验证集选训练轮数/配置，避免拿测试子集反复调参。本轮没有基于测试结果继续改参数。

## 本地文件

运行目录：`runs/local-qlora-v1/`。

- [适配器下载包](runs/local-qlora-v1/local-adapter-and-report.zip)：包内 `adapter/` 包含权重及处理器配置，可与相同 2B 底座一起加载。
- [完整报告](runs/local-qlora-v1/REPORT.md)：本轮完成状态和指标。
- [训练结果](runs/local-qlora-v1/training-result.json)：训练步数、验证损失、显存与权重哈希。
- [生成对照](runs/local-qlora-v1/comparison.json)：底座/微调后及共同合规样本的比较。
- `base-predictions.json / lora-predictions.json`：真实原始文本与解析结果。
- `training-loss.jsonl / validation.json / configuration.json`：完整记录。
- `checkpoints/`：第 10/20/30 步和轮次结束时的适配器检查点。

本轮适配器压缩包、原始预测与关键实验记录按要求提交到 Git；原始主题、完整训练图片和中间检查点保留本地。`runs/local-qlora-v1/local-adapter-and-report.zip` 不包含底座模型权重。这个适配器对应 Qwen3-VL-2B，不能直接挂到结构/维度不同的 8B 底座上。

## 复现命令

在项目根目录执行，使用新的运行目录保留旧实验：

```powershell
$env:HF_HUB_OFFLINE='1'
.\.venv-ml\Scripts\python.exe theme-layout-dataset/local_finetune.py --bundle theme-layout-dataset/runs/auto-pairs-v1/server-bundle --model artifacts/models/Qwen3-VL-2B-Instruct-sharded --run theme-layout-dataset/runs/local-qlora-v2
.\.venv-ml\Scripts\python.exe theme-layout-dataset/evaluate_local_finetune.py --run theme-layout-dataset/runs/local-qlora-v2
```

程序检查源图路径、答案掩码、有限损失/梯度及参数真实更新。没有仅生成训练脚本就将任务报告为完成。
