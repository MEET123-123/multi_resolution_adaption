# Qwen3-VL mock 微调实验记录

日期：2026-10-19。当前阶段只验证合成数据上的工程闭环；没有完成真实主题的模型质量验收。

## 已实际运行的链路

生成 mock 主题 → 复用原解析器和组件推断 → 缓存三层标签及源图 → 导出 SFT → QLoRA 微调 → 保留测试样本推理 → JSON 协议校验 → 原约束求解器 → 自动评价 → XML 候选写回审计。

本次成功训练没有使用真实主题包。早期准备的真实弱标签及失败的加载诊断位于其他实验目录，不属于本次训练结果。

最终代码回归：262 项测试通过，耗时 27.312 秒。另从新目录重建 3 套 mock 主题并导出 SFT，切分为 2 train / 2 validation / 2 test，未遗漏输入图片。完整测试包含本地 HTTP 服务，使用允许本机服务的执行环境。

## 微调结果

| 指标 | 实测 |
|---|---:|
| 优化步数 | 12 |
| LoRA rank | 8 |
| 可训练参数 | 3,211,264 |
| 实际发生变化的适配器张量 | 224 |
| 训练显存峰值（已分配） | 3.83 GiB |
| 训练耗时（不含底座加载） | 44.78 秒 |
| 首步 / 末步训练 loss | 0.422602 / 0.141795 |

采用 4 位 NF4、冻结视觉编码器、语言注意力投影 LoRA、微批次 1、梯度检查点。图像预算 50,176 像素，token 上限 8,192。只监督助手答案 token。

训练 loss 来自不同样本，不能当成固定测试集性能。validation 切分已保留，本次短实验没有计算验证 loss，也没有用于选择超参数或模型检查点。

## 同一组保留测试样本的对照

| 指标 | 未微调底座 | 本次 LoRA |
|---|---:|---:|
| 满足完整组 ID 协议的输出 | 0 / 2 | 2 / 2 |
| 原因 | 两次均只返回 g0，遗漏其他四组 | 返回完整五组 |

两组推理均使用同一模型、源图、JSON、解码与 token 预算；没有把目标参考图放进输入。原始模型文本已保存，非法输出单独计数，不将回退算法的结果计成模型成功。

| LoRA 后续检查 | 原始提案 | 经原有求解器 |
|---|---:|---:|
| 布局评价条目 | 24 pass / 8 fail | 32 pass / 0 fail |
| 与合成目标的坐标 MAE（0–1000，xywh） | 23.8017 | 6.3691 |
| XML 候选写回审计 | — | 2 / 2 通过 |

这说明原有约束求解器仍然起主要的几何保护作用，不能把投影后的改善全部归因于模型。

**自动质量门禁拒绝采用候选。** 两个场景的美学代理分数分别从 97.317517 降至 96.494449、从 95.331670 降至 94.575386。系统保留原算法；两份 XML 仅输出到 `scripts-for-review/`，`qualitySelected=false`。写回审计通过不等于布局质量胜出。

## 复用接口与边界

- 元素级：脚本属性、源节点 ID、资源引用、脚本框、可见框和缺失原因。
- 语义级：时间/日期/天气等标签、依赖来源、置信度、组件归属；支持人工覆盖。
- 组合级：居中、贴边、关系、交互路径、布局类型及留白候选。留白是规则推断，未训练显著性检测模型。
- 批量标注从 JSONL/SQLite 缓存读取，分页 API、版本冲突检查与 SFT 再导出不重新提取脚本。
- 原生双形态配对需要确认组件对应；目标参考图只用于审核，默认不进入模型输入。
- 可替换模型加载器和外部推理服务；双卡 Linux DDP 启动入口已提供，2×32GB 服务器尚未实测。
- 离线渲染不代表鸿蒙真机。动画全过程、真实复杂主题与更大底座仍需后续单独验收。
