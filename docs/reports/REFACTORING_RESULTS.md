## 使用边界

这是可运行的设计驱动响应式 MVP。静态设计 JSON 没有覆盖所有旧主题脚本、动画、视频和连续交互；这些继续由 Python 引擎处理。自动模式交付逐设备脚本，不生成与预览不等价的“任意设备通用”线性单文件。鸿蒙 5+ 引擎迁移仍是独立工作。
