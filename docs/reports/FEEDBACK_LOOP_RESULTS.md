# 自动评测反馈闭环：实施与验证记录

日期：2026-10-19。依据用户提供的 `theme/recircle.md`，结合 ReDeCheck 的响应式关系图方法增量实现。没有引入新的运行时依赖或复制第三方源码；SQLite、进程池来自 Python 标准库，图像证据复用项目已有 Pillow 渲染器。

## 已实现

- 评价、修复提案、布局算法三个独立接口；自定义 `layout_scene` 接口保持兼容。
- 从源可见边界推断组件组中心，稳定样本一致时提升为强制约束；独立评测重新测量，不依赖 solver 是否写了 centerAxes。
- FAIL / REVIEW / UNKNOWN / PASS / 不适用分开；默认不把探索截断、未回放、历史未绑定报告当作通过。
- badcase 包含组件、数值证据、动作轨迹、源/目标状态、输入摘要、评价器版本与复现快照；聚类只标为疑似原因。
- 有预算的原图、目标图、标注图；透明/媒体/不支持的绘制不伪装成原生证据。
- 多步交互事务、控制值对照、调试历史恢复；宽/高关系图采样、断点邻域与变化区间二分。
- 候选独立生成，逐规则/逐状态回归、原始状态及资源不变性检查、XML 审计，通过后保留候选预览；不覆盖源包或有效缓存。
- CLI 标注历史、人工/规则确认后的固定用例、主题级数据划分、通过样本抽查。
- 流式汇总、共享轨迹、SQLite Case ID 索引、源项目快照、进程隔离及中断恢复。

## 闭环实验

### 已知注入错误

在独立 mock 缓存中注入时间组的水平偏移，源样例保持只读。

- `closure-before`：34 条检查，3 FAIL、6 UNKNOWN。
- `closure-after`：34 条检查，0 FAIL、6 UNKNOWN。
- 逐项比较：3 项改善，0 新回归，0 检查缺失。
- 候选通过 XML 写回和脚本保真审计，保存预览与项目副本。
- 已知注入案例经 `synthetic-fixture` 标签冻结，固定回归通过。这是合成真值，不是设计师标注数据。
- `responsive-final`：修复样例的 39 条检查中 34 PASS、5 UNKNOWN；完成两个视口采样路径和一个交互轨迹。未知项未改写为通过。

### 真实北海主题

反馈定位到一个通用规则缺口：底部等分组件的布局按图片画布中心计算，居中检查按 alpha 可见中心计算；同时 rail 分支跳过了已有的居中约束。

修复方式：底部横向分布统一使用光学边界；稳定的居中约束不再因组件属于等分行而被跳过；纵向底边仍使用原来的行基准。其他主题也使用这套规则，无主题名特判。

- 修复前：1,085 条检查，22 条居中失败。
- `beihai-center-fixed`：1,085 条检查，1,059 PASS、26 UNKNOWN，0 FAIL。
- 自动保留通过门禁的候选；有效主题缓存和原始 HWT 未覆盖。
- 26 个未知项涉及未穷尽的交互/视口范围和未绑定的历史报告，仍需继续验证。
- 22 个目标脚本全部通过现有写回审计；规则确认的北海居中案例已冻结，候选上的固定回归通过。该确认来自源关系和用户要求的审计，不作为设计师美学标注。

## 资源与恢复验证

首轮并发评测曾造成内存压力：全尺寸图片的条目数缓存、全量 JSON 反序列化及同时运行的测试任务叠加，出现 MemoryError。该轮失败没有被算作通过。

改为流式读取/汇总，共享通过样本的动作轨迹；绘制设置像素预算并在每个视图结束清理图片缓存。预算外图片标为 UNKNOWN。已完成主题保存独立报告，恢复时验证输入摘要、源摘要、配置和评价器版本；不完整目录保留到 `interrupted/`。全量任务最终完成，25 个输入快照与原缓存摘要匹配。

后续增加评价器或改变规则语义时应升级插件版本；不要拿不同规则版本的分数直接比较。受信任的 Python 插件仍须遵守只读接口；外部模型和可能阻塞的插件需要单独的进程级执行期限。

## 原生与模型边界

- 尚未做华为真机安装、展开/旋转、锁屏系统控件和原生媒体效果验收。
- 尚未接入 IQA/视觉模型或设计师金标准，未训练排序器。
- 未对不同分辨率整图直接计算像素相似度。
- 交互回放来自离线解释器，外部系统操作只记录，不真实启动相机等应用。

使用、插件接口、配置和回滚方法见 [反馈闭环指南](../guides/FEEDBACK_LOOP.md)。
