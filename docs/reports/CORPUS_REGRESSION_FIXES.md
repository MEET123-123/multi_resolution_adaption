# 全主题回归修复

基线提交：`ff6231b`。该版本的 24 个主题、25 套锁屏脚本、平板两个方向共 50 个案例中，有 6 个失败案例。

## 原因与通用修复

| 原失败案例 | 原因 | 修复 |
| --- | --- | --- |
| 事事如意 3D熊猫，竖屏/横屏 | 偶然重合产生跨页面物理绑定；局部重排沿用可见姿态，将屏外卡片带回画布 | 多姿态绑定一致性、隐藏场景结构推断、完整屏外组件的求解约束 |
| 五福临门，横屏 | 点击/滑动判定藏在公共变量中，未进行逆坐标映射 | 只展开纯计算触摸依赖，按下捕获变换，并保留原有事件树 |
| 疯癫杀马特，横屏 | 无视觉资源的长热区被按图像比例缩放并上移，遮挡另一个按钮 | 独立热区按屏幕两个轴映射，保留本地输入逆变换 |
| 暹罗厘普，竖屏/横屏 | 指针反馈与调整前的模拟触点比较，被当作稳定内容检查 | 按实际触点计算预期反馈，保留错误偏移检测 |

所有修复均基于结构、依赖、可见几何及交互数据，算法不包含上述主题名称或专属坐标。

## 复核与保护

- 最终资源几何重新检查，不沿用优化前的外框警告。
- 外框交错的组件增加资源级分离关系，保留原本不重叠的资源顺序和间距。
- 原始分离的局部按钮增加热区分离约束，避免重排后覆盖另一按钮、阻断连续交互。全屏手势、原有重叠及弹窗保持各自语义。
- 原始空按下事件与生成的坐标捕获事件分别识别；业务条件、原始子节点和指令顺序仍受保护。
- 坐标捕获使用独立且无条件执行的按下事件，原有条件按下事件不再承担坐标初始化职责。
- 静态控件保留当前场景中每个实例的几何；只有序列帧、视频等媒体沿用首帧。实际已出现的控件覆盖旧缓存中的未激活标记。
- 明确报告缺失的手机自定义图片、颜色表达式和原生效果，保留不完整状态。
- 新增回归覆盖间接触摸判断、保留可写变量、偶然相交、独立热区、局部重排屏外页面、指针位置及故意损坏后的拒绝行为。
