## 示例用途与验证

示例包中的图像、几何和语义均为格式演示，没有真实主题、执行记录、人工批准或真机证据，不可作为训练真值。审核模板中的approved仅用于演示字段格式，不能导入生产数据集。建议sidecar并不代表现有CLI已经实现其导入功能。

在本目录执行只读校验，无需运行主题引擎或联网：

```powershell
python 数据集标注结构示例包/validate_examples.py
```

提交前已检查示例文件引用、请求摘要、组ID及JSON格式，并用当前工程的validate_answer和validate_annotation_edits核对布局答案与审核字段。该检查不代表完成主题运行或设备验收。

## 重新生成

使用Python 3.10或更新版本，安装reportlab、pypdf、Pillow；字体配置使用Windows的微软雅黑和Arial，其他系统需要调整脚本中的字体路径。

```powershell
python build_report.py
python build_annotation_examples.py
```

第一个脚本从本目录Markdown生成PDF及本地质量摘要。第二个脚本重新生成虚构结构示例和本地ZIP，不会建立真实训练集。PDF发布前应渲染并检查分页、表格、中文字体与链接。

原始主题包、真实用户素材、审核数据库、训练产物、临时分页图和历史备份不在本目录中。
