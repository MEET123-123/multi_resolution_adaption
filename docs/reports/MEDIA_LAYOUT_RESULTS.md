# 媒体首帧布局结果

2026-10-17。规则与算法接口见 [ANCHOR_LAYOUT.md](../guides/ANCHOR_LAYOUT.md#序列帧与视频首帧布局)。

## 已实现

- 序列帧、视频采用首帧画布作为布局参考。后续帧沿用同一组件变换 `{sx, sy, tx, ty}`；播放、原位移与透明度变化继续执行。
- 支持时间驱动的 `srcid`、常见字符串前缀 `srcExp`、`SourcesAnimation/Source`，以及视频固定画布。数字/文字字形的 `ImageSeries` 不视为普通动画序列。
- 首帧透明时保留画布；零尺寸入场可使用首帧素材的自然尺寸并记录原因。暂停仍沿用首帧参考。缺失或无法解析的画布进入诊断。
- 帧尺寸不同时按实际尺寸乘同一尺度，避免将每张图强拉到首帧尺寸。原素材不改写、不转码。
- 媒体播放相位不参与媒体布局变换选择；人工换页、样式状态及非媒体页面所需的时钟条件继续保留。
- 实时预览增加“采样媒体动画”：默认 0–2400ms、100ms 步长，源/目标同时采样，可拖动或播放；不新增交互场景、历史记录或布局求解。
- 首帧参考使用紧凑节点索引，避免每个设备/状态重复保存完整 XML 路径。自有算法读取 `context.mediaLayout`，用 `context.nodeOrder` 将索引对应回节点 ID，原函数接口不变。

## 边界

首帧布局不保证动画移动后的每一帧均在安全区内。延迟出现的可见性只在固定相位做有界探测；探测窗口外的短暂出现仍需补充采样。首帧资源缺失、外部系统/相册资源、复杂原生控制命令、缓动、旋转、字形缩放及原生视频解码仍需要对应输入与实机验证。

某真实主题的索引表达式含 `#12xs` 这类预览器尚不能解释的变量名。对等尺寸帧保留统一原生画布，避免把有效图片尺寸写成零；原表达式原样保留，并记录诊断。该项不计入跨帧源表达式已解析的通过样本。

布局选择数量不是审美通过率。分组、裁剪与构图仍可在预览中复核，并通过已有锚点配置或自有算法调整。
