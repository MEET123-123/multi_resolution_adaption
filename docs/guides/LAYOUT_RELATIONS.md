# 居中、边缘与上下间距

## 自动判断的顺序

1. 对每个轴分别判断居中。PNG 使用 alpha ≥ 16 的可见内容范围，原位图和透明留白保持不变。
2. 该轴存在居中证据时优先居中；否则判断贴边与脚本中的屏幕边缘表达式。
3. 没有居中、贴边证据时，按原始九宫格位置和相对偏移求解。
4. 主背景按自身画布计算 cover；分层装饰保留原组合画布的构图变换。保留原图在各轴上的裁切位置，例如横向居中、纵向靠上。

## 上下左右的约束

- 底部两端的独立快捷控件先按图片与按钮绑定拆分。手电筒使用左下角、相机使用右下角；两者保留水平对齐，各自边距跟随资源等比缩放，不再作为一个整体居中的宽组。识别范围包括从时钟大组中拆出的底部内容分区，以及本来已独立的左右控件。
- 角落锚点采用原始场景中已到位的图片画框，而非可能在屏外的动画首帧。后续帧沿用同一变换；原作者通过交互改变位置的场景释放角落约束，返回原布局时恢复。图片与其点击区域共同移动。
- 上方内容与底部角落控件按上下区域保留次序和最小间距，不因为横向投影不相交就推断为左右邻居。区域约束不再额外优化远距离间距，防止按钮贴边时把上方时间横向拉偏或挤到屏幕顶部。
- 在原始画布的实际可见范围中识别共用的左、右、上、下边线和中心线。跨组件组共用同一条对齐线求解，不能因分别缩放、居中或贴边而产生错位；每对组件每轴选一条最有证据的线，避免误把对齐变成强制等宽、等高。
- 自动行列容器保留原本的起边、中心或末边对齐，并考虑透明边距；没有共同对齐线时保留原本的横向或纵向偏移，不再默认全部居中。人工配置的容器对齐保持优先。
- 使用解析后的全局坐标判断对齐；不同父级中数值相同的局部坐标不能作为配对证据。同一交互条件的多帧中，只有共同可见时始终成立的对齐关系才固定，避免把运动途中偶然相遇当成布局约束。
- 公共组件锁定若阻止新组件保持对齐，扩大推断的局部重排范围。美学优化投影和最终导出再次检查跨组对齐，防止后处理重新造成错位。源坐标识别误差为 0.01 逻辑像素，求解器以零偏差为偏好、0.005 逻辑像素为硬界限，导出复核允许 0.1 逻辑像素的数值误差。
- 原本没有相交的可见组件，保留至少一个分离轴和先后次序；已有叠加关系不强行拆开。
- 上下间距按目标高度计算，左右间距按目标宽度计算。相邻元素的间距偏好优先于远距离元素，空间不足时允许压缩空白但不能新增组件重叠。
- 美学搜索不能把已经保留的合理间距再次挤小，也不能破坏居中、固定公共组件和画布范围的约束。
- 大组内可独立的上下区段可拆开排布；遮罩背景与提示分离，按钮跟随对应内容。无法安全拆分的动画父级保留原组。
- 紧邻底部按钮、包含指向提示的宽图片与按钮使用同一个变换，保留箭头和目标的相对位置。
- 同一原生交互条件下的播放阶段共用变换；序列帧和视频后续帧继续沿用首帧变换。
- 交互使同一组节点换位时，将其识别为变化组件；没有变化的公共组件继续复用。
- 新内容插入后若被贴边公共组件挡住，先扩大局部重排范围；同一原生交互条件的多阶段不能共用局部方案时，整批阶段在首个场景中求解整页布局，再共用变换。明确配置的人工约束保持强制执行。
- 首帧资源不可解析、尺寸为零时，采用已解析的可见几何参与求解，避免把随后出现的元素漏掉。

## 验证与范围

`tests/validate_spatial_flow_real.py` 检查全部缓存状态、设备方向、源图分离关系、严格居中和导出约束。`tests/validate_canvas_real.py` 检查稳定可见资源的画布范围。原有入场、离场与屏外等待内容保留。

验证作用于已解析的组件和已采样状态。单张位图中绘制的多项内容不会被任意切开；解释器验证不能替代原生设备验收。

输出仍为 `theme/adaptation/<主题编号>/scenes/scripts/` 和 `scenes/packages/`。原始 HWT 不改写。自定义布局算法接口保持 `layout_scene(...) → {组件编号: {sx, sy, tx, ty}}`。

完整 IR 与约束诊断保存在各项目的 `anchor-layout.json`。`project.json` 用 `anchorIRArtifact` 和 `anchorIRCount` 引用它，预览仅携带诊断摘要，避免重复加载完整求解依据。
