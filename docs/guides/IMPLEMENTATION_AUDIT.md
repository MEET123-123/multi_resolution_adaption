# 布局模型 MVP：现有接口审计

本次以用户提供的《数据集构建与多模态模型微调实施指南》为参考。优先验证 mock 微调；真实双形态主题的数据入口保留。

## 已复用的能力

| 现有入口 | 实际职责 | 本次用法 |
|---|---|---|
| `pipeline/scene_pipeline.py::create_project` | 解析脚本、资源、运行时场景、组件、目标设备 | 初次构建缓存，以及生成 mock 主题 |
| `SceneLayoutAlgorithm.layout_scene` | 返回组件的 `{sx,sy,tx,ty}`，使用引擎逻辑坐标 | 最终执行契约保持不变 |
| `pipeline/scene_clusters.py::schedule_device` | 公共组件冻结、局部重排、弹层、布局复用 | 分派模型候选；复用场景无需重复调用 |
| `layout/anchor_ir.py::build_ir` | 根组件组、层级、锚点、居中、边缘关系 | 导出组标签及稳定对应关系 |
| `layout/anchor_layout.py` / `anchor_solver.py` | Kiwi 求解、组内资源统一缩放、画布/间距等约束 | 增加一个默认无操作的软提案钩子 |
| `layout/aesthetic_layout.py`、`clock_semantics.py` | 原生时间标签与变量依赖 | 语义标注遵循同样的脚本优先原则 |
| `interaction/interaction_bindings.py` | 按钮与可视组件关联 | 缓存模型和交互路径保留对应关系 |
| `preview/paint_visibility.py` | 离线栅格绘制及可见性证据 | 复用绘制器，限制图片内存预算 |
| `preview/scene_previewer.py` | 现有原始/适配交互预览 | 保留；训练标注页面复用同一场景和变换数据 |
| `evaluation/` | 居中、边界、重叠、公共组件、关系、美学代理与候选门禁 | 模型结果和现有布局算法进行同批对照 |
| `scene_pipeline.py::export_script` | 精确反写与现有约束/词法审计 | 只对候选导出；源脚本保持只读 |

## 两个坐标接口

模型输出统一为 `multires-layout/1`，格式为 `groups: {g0: [x,y,w,h]}`。数值相对目标安全区域归一化到 1000。模型不能返回资源、触发器或节点增删。

`LearnedAnchor` 将组框转为软几何目标，投影到等比资源缩放，然后调用原求解器。最终仍返回原生组件变换。源元素框使用源画布归一化坐标，输入明确标记两种坐标系。

这一版只开放根组件组的位置和尺寸。元素级可以检查和标注语义；组内任意拆分重排、`element_overrides` 尚未开放。需要此能力时应升级契约，不能静默把它当作刚性组变换。

## 标签证据分层

- 元素层：原节点 ID、运行时实例 ID、脚本框、可见框、资源、父子关系、原始表达式。
- 语义层：时间/日期等标签、组件身份、语义来源和置信度。无法识别时保留 `unknown`。
- 组合层：组层级、锚点、居中、边缘、对齐、交互路径、场景意图及留白候选。

脚本框与 alpha 元数据推导的可见框分开存储。文本或原生效果的可见框无法可靠测量时为 `null`，同时记录原因。

## 验证边界

mock 标签来自明确记录的合成坐标修复任务：修复人为加入的坐标扰动，参考答案来自确定性布局规则。它们验证训练和执行链路，不代表人工设计正确性或真实主题泛化能力。

离线绘制不等同于鸿蒙原生渲染。留白算法是网格占用率和图像边缘对比度代理，没有把它称为语义显著性检测。实际训练和检查结果记录在 `reports/QWEN_MVP_RESULTS.md`。
